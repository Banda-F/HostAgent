# 🤖 HostAgent — AI-агент для заработка на партнёрских программах хостингов

## Что это?

**HostAgent** — это умный AI-ассистент, который помогает вебмастерам, блогерам и фрилансерам зарабатывать на партнёрских (affiliate) программах российских хостинг-провайдеров. Агент автоматически анализирует условия, подбирает оптимальные хостинги для рекомендаций, генерирует готовый контент с партнёрскими ссылками и отслеживает эффективность.

## Ключевые возможности

| Функция | Описание |
|---------|----------|
| 🧠 **Умный подбор хостинга** | Анализирует потребности пользователя и подбирает лучший хостинг с максимальным доходом |
| 📊 **Аналитика партнёрок** | Сравнение комиссий, условий выплат, минимальных сумм вывода |
| ✍️ **Генерация контента** | Создание готовых постов, статей, отзывов с встроенными партнёрскими ссылками |
| 🔗 **Менеджер ссылок** | Управление партнёрскими ссылками, автоматическая маскировка и UTM-метки |
| 📈 **Трекинг эффективности** | Отслеживание кликов, конверсий и прогнозирование дохода |
| 💰 **Оптимизация дохода** | Рекомендации по диверсификации и увеличению заработка |
| 🤖 **Telegram-бот** | Полноценный интерфейс через Telegram для работы на ходу |
| 📉 **Веб-дашборд** | Визуальная аналитика и управление через веб-интерфейс |

## Поддерживаемые хостинг-провайдеры

| Провайдер | Комиссия | Повторные | Особенности |
|-----------|----------|-----------|-------------|
| **Beget** | 10–40% | ✅ Да | Прогрессивная шкала по тарифам |
| **Timeweb** | 20–40% | ✅ Да | 40% хостинг, 20% VDS |
| **Reg.ru** | ~40% | ✅ Да | 40% от каждого платежа |
| **SpaceWeb** | до 30% | ✅ Да | Стабильная программа |
| **Sprinthost** | до 40% | ✅ Да | 2-уровневая (+10% от рефералов 2-го уровня) |
| **FirstVDS** | 10% | ✅ Да | Пожизненно + скидка 25% для клиента |
| **Aéza** | 15–50% | ✅ Да | Прогрессивная до 50% |
| **Hostinger** | 40–60% | ❌ Нет | Разовая выплата, высокая ставка |

## Быстрый старт

### 1. Установка
```bash
git clone https://github.com/your-repo/hostagent.git
cd hostagent
pip install -r requirements.txt
```

### 2. Конфигурация
```bash
cp config/config.example.yaml config/config.yaml
# Заполните свои ключи API и токены
```

### 3. Запуск
```bash
# Запуск Telegram-бота
python -m src.services.telegram_bot.bot

# Запуск веб-дашборда
python -m src.services.web_dashboard.app

# Запуск сборщика данных
python -m src.data.parsers.collector

# Полный запуск (все компоненты)
python main.py --all
```

## Технологии

- **Python 3.11+** — основной язык
- **OpenAI API / локальные LLM** — интеллект агента
- **SQLite** — база данных (без внешних зависимостей)
- **python-telegram-bot** — Telegram-интерфейс
- **FastAPI + Jinja2** — веб-дашборд
- **BeautifulSoup + httpx** — сбор данных
- **APScheduler** — планирование задач

## Требования

- Python 3.11+
- OpenAI API ключ (или доступ к совместимому LLM API)
- Telegram Bot Token (для бота)
- Всё остальное из свободного доступа
