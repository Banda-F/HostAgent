# Архитектура HostAgent

## Концепция Multi-Agent системы

HostAgent построен по паттерну **Multi-Agent Orchestrator** — центральный оркестратор направляет запросы пользователя к специализированным агентам, каждый из которых отвечает за свою область.

```
                    ┌──────────────────┐
                    │   Пользователь    │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  Telegram Bot /  │
                    │  Web Dashboard   │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │   Orchestrator   │  ← Ядро: определяет какой агент вызвать
                    │   (Router)       │
                    └────────┬─────────┘
                             │
            ┌────────────────┼────────────────┐
            │                │                │
   ┌────────▼───────┐ ┌─────▼──────────┐ ┌───▼──────────────┐
   │  Analyst Agent  │ │ Content Agent  │ │  Link Agent       │
   │                 │ │                │ │                   │
   │ • Анализ        │ │ • Генерация    │ │ • Создание ссылок │
   │   партнёрок    │ │   контента     │ │ • UTM-метки      │
   │ • Сравнение     │ │ • Посты для    │ │ • Трекинг кликов  │
   │   условий      │ │   соцсетей     │ │ • Маскировка      │
   │ • Прогноз       │ │ • Статьи       │ │   ссылок          │
   │   дохода       │ │ • Обзоры       │ │ • Аналитика       │
   │ • Рекомендации  │ │ • Отзывы       │ │   переходов      │
   └────────────────┘ └────────────────┘ └───────────────────┘
            │                │                │
            └────────────────┼────────────────┘
                             │
                    ┌────────▼─────────┐
                    │  Data Layer      │
                    │  (SQLite + JSON) │
                    └──────────────────┘
```

## Потоки данных

### 1. Сбор данных (Data Collection Pipeline)
```
Парсеры → RSS/Atom → API хостингов → База данных → Кэш JSON
```

### 2. Обработка запроса пользователя
```
Пользователь → Orchestrator → [Классификация意图] → Агент → LLM → Ответ
                                                              ↓
                                                     Обновление БД
```

### 3. Генерация контента
```
Запрос → Content Agent → LLM (с промптом + данные БД) → Контент
                                                              ↓
                                                     Вставка партнёрских ссылок
                                                              ↓
                                                     Сохранение в БД
```

## База данных (SQLite)

### Таблицы:
1. **hosting_providers** — провайдеры и их условия
2. **affiliate_programs** — детали партнёрских программ
3. **hosting_plans** — тарифные планы
4. **user_profiles** — профили пользователей агента
5. **affiliate_links** — партнёрские ссылки пользователя
6. **content_pieces** — сгенерированный контент
7. **click_events** — лог кликов по ссылкам
8. **reviews_scraped** — собранные отзывы о хостингах

## AI-промпты

Все промпты вынесены в `prompts/` и редактируются без изменения кода:
- `system.txt` — системный промпт агента
- `analyst.txt` — промпт аналитика
- `content_creator.txt` — промпт генератора контента
- `link_optimizer.txt` — промпт оптимизатора ссылок

## Без внешних платных API

Вся информация о хостингах собирается из публичных источников:
- Официальные сайты хостинг-провайдеров
- Страницы партнёрских программ
- Публичные тарифы и условия
- ru.hostings.info — агрегатор отзывов
