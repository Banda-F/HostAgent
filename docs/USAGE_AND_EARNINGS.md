# ЧАСТЬ 1. Запуск бота на локальном компьютере (Windows)

## Предварительные требования

Убедитесь, что у вас установлены:
- **Python 3.11 или новее** → скачать: https://www.python.org/downloads/
  ⚠️ При установке поставьте галочку **«Add Python to PATH»**
- Доступ к интернету

Проверить установку Python:
```cmd
python --version
```
Должно показать `Python 3.11.x` или новее.

---

## Шаг 1. Откройте командную строку в папке проекта

1. Нажмите `Win + R`
2. Введите `cmd` → Enter
3. Перейдите в папку проекта:
```cmd
cd /d "D:\ai hosting"
```

---

## Шаг 2. Создайте виртуальное окружение

```cmd
python -m venv venv
```

Это создаст папку `venv` с изолированной средой Python. Ждём завершения.

---

## Шаг 3. Активируйте виртуальное окружение

```cmd
venv\Scripts\activate
```

✅ Признак успеха — в начале строки появится `(venv)`:
```
(venv) D:\ai hosting>
```

> ⚠️ **Важно:** Каждый раз при открытии НОВОГО окна cmd нужно заново
> выполнять `cd /d "D:\ai hosting"` и `venv\Scripts\activate`.

---

## Шаг 4. Установите зависимости

```cmd
pip install -r requirements.txt
```

Процесс займёт 2–5 минут. Скачаются все необходимые библиотеки.
Если есть ошибки — попробуйте обновить pip:
```cmd
python -m pip install --upgrade pip
```

---

## Шаг 5. Проверьте конфигурацию

Файл `D:\ai hosting\config\config.yaml` уже должен содержать:
- `api_key` (ваш ключ OpenAI)
- `bot_token` (токен от @BotFather)

Откройте файл в Блокноте и убедитесь, что значения заполнены
(нет `your-...` заглушек).

---

## Шаг 6. Первый запуск — сбор данных о хостингах

```cmd
python main.py collect
```

Эта команда:
- Создаст базу данных `data\hostagent.db`
- Заполнит её информацией о 8 хостингах
- Попробует обновить данные с официальных сайтов

✅ Признак успеха — в конце лога:
```
Collection done. Success: 8, Failed: 0
```

> ⚠️ Если часть хостингов не спарсилась (Failed > 0) — не страшно.
> В базе уже есть базовые данные из seed, бот будет работать.

---

## Шаг 7. Запуск Telegram-бота

```cmd
python main.py bot
```

✅ Признак успеха:
```
Starting Telegram bot (polling)...
```
Процесс НЕ должен завершаться — бот работает и ждёт сообщений.

**Не закрывайте это окно cmd!** Пока оно открыто — бот работает.

---

## Шаг 8. Проверьте бота в Telegram

1. Откройте Telegram
2. Найдите вашего бота по username (который вы задали в @BotFather)
3. Нажмите **«Запустить»** или отправьте `/start`
4. Бот должен ответить приветствием с кнопками

🎉 **Поздравляю, бот работает!**

---

## Шаг 8а (опционально). Запуск веб-дашборда

Откройте **ВТОРОЕ** окно cmd (первое оставьте с ботом):
```cmd
cd /d "D:\ai hosting"
venv\Scripts\activate
python main.py web
```

Откройте в браузере: **http://127.0.0.1:8080**

---

## Как остановить бота

В окне cmd нажмите `Ctrl + C`.

---

## Возможные проблемы при запуске

| Проблема | Решение |
|----------|---------|
| `'python' is not recognized` | Переустановите Python с галочкой "Add to PATH" |
| `ModuleNotFoundError` | Вы забыли `venv\Scripts\activate` или `pip install -r requirements.txt` |
| `Conflicting versions` при установке | `pip install --upgrade pip` и повторить |
| Бот молчит в Telegram | Проверьте `bot_token` в config.yaml и что нет другого бота с этим токеном |
| `401 Unauthorized` от OpenAI | Неправильный `api_key` или нет средств на балансе OpenAI |
| `Telegram conflict` | Другой экземпляр бота уже запущен — закройте все окна cmd с ботом |
| Бот упал с ошибкой | Прочитайте текст ошибки в консоли, обычно там указана причина |

# ЧАСТЬ 2. Использование бота

## Быстрый старт (после /start)

Бот предлагает главные кнопки:
- 📊 Анализ хостингов
- ✍️ Создать контент
- 🔗 Мои ссылки
- 💰 Прогноз дохода
- ❓ Помощь

Можно **нажимать кнопки** ИЛИ **писать текстом** — бот понимает естественную речь.

---

## Все команды бота

### 📋 Навигация

| Команда | Что делает |
|---------|-----------|
| `/start` | Приветствие + кнопки |
| `/help` | Полная справка |
| `/top` | Топ-5 хостингов по размеру комиссии |

### 📊 Анализ и подбор

| Команда | Пример |
|---------|--------|
| `/analyze` | `/analyze Сравни Beget и Timeweb` |
| `/analyze` | `/analyze Какой хостинг лучше для WordPress` |
| `/analyze` | `/analyze Хостинг с максимальной комиссией` |

Или просто текстом: *"Сравни Beget и Timeweb для интернет-магазина"*

### ✍️ Генерация контента

| Команда | Пример |
|---------|--------|
| `/content` | `/content пост про Beget для Telegram` |
| `/content` | `/content обзор Timeweb` |
| `/content` | `/content сравнение Beget и Reg.ru` |
| `/content` | `/content статья про выбор хостинга для новичков` |

Бот создаёт **готовый текст**, в который вставляет вашу партнёрскую ссылку.

### 🔗 Управление ссылками

| Команда | Что делает |
|---------|-----------|
| `/addlink URL` | Добавить партнёрскую ссылку |
| `/links` | Показать все ваши ссылки + статистику |

Пример:
```
/addlink https://beget.com/?ref=вашкод
```
Бот сам определит хостинг и создаст короткую ссылку для отслеживания кликов.

### 💰 Прогноз дохода

| Команда | Пример |
|---------|--------|
| `/forecast` | `/forecast у меня 2000 подписчиков в Telegram` |
| `/forecast` | `/forecast блог 5000 посетителей в месяц` |
| `/forecast` | `/forecast веб-студия 10 клиентов в месяц` |

Бот считает три сценария: пессимистичный, реалистичный, оптимистичный.

### 📈 Статистика

| Команда | Что показывает |
|---------|---------------|
| `/stats` | Клики, конверсии, заработок по вашим ссылкам |

---

## Типовой рабочий процесс (workflow)

Вот как выглядит **полный цикл работы** с ботом от старта до заработка:

```
1. /top                          → выбираете хостинг с хорошей комиссией
2. Регистрируетесь в партнёрке   → получаете реф-ссылку на сайте хостинга
3. /addlink ваша_ссылка          → бот добавляет её в систему
4. /content пост про ХОСТИНГ     → бот генерирует готовый пост со ссылкой
5. Копируете пост                → публикуете в свой Telegram/блог
6. /stats                        → следите за кликами и заработком
7. /forecast                     → понимаете потенциал масштабирования
```

# ЧАСТЬ 3. Продвижение и заработок первых денег

## 🏆 Анализ рынка (2025–2026)

### Почему ниша хостинга — одна из лучших для партнёрок:

| Фактор | Значение для вас |
|--------|------------------|
| **Recurring (повторные) выплаты** | Привлекли клиента ОДИН раз → получаете % КАЖДЫЙ месяц, пока он платит |
| **Высокие комиссии** | 30–60% — это очень много (для сравнения, у Amazon 1–4%) |
| **Низкий порог входа** | Регистрация в партнёрках бесплатная, без проверок |
| **Долгий LTV** | Клиент хостинга платит в среднем 12–18 месяцев (иногда годы) |
| **Эффект снежного кома** | Каждый месяц новый клиент добавляется к старым → доход растёт |

### Ключевой инсигхт рынка
> Большинство вебмастеров продвигают ОДИН хостинг вслепую.
> Ваше преимущество с HostAgent: **умный анализ + готовый контент**.
> Вы знаете, КАКОЙ хостинг рекомендовать КАКОЙ аудитории, и имеете
> текст, который конвертирует. Это даёт конверсию в 2–3 раза выше средней.

---

## 🎯 Рабочая схема заработка (пошаговая)

### ЭТАП 0. Подготовка (1 день)

1. **Зарегистрируйтесь в 3–4 партнёрках** (не во всех сразу!):
   - ✅ **Timeweb** — самая известная в РФ, легко продаётся
   - ✅ **Beget** — отличная репутация, высокий % (40%)
   - ✅ **Sprinthost** — 2-уровневая система (пассивный доход с рефералов)
   - ✅ **Reg.ru** — широкая узнаваемость бренда

2. **Получите реф-ссылки** в личном кабинете каждого хостинга

3. **Добавьте ссылки в бота**:
   ```
   /addlink https://timeweb.com/ru?ref=ваш_код
   /addlink https://beget.com/?ref=ваш_код
   ```

### ЭТАП 1. Первые деньги БЕЗ сайта (1–4 недели)

#### Стратегия «Эксперт в комментариях» (0 рублей вложений)
1. Найдите тематические сообщества:
   - Telegram-чаты по веб-разработке, WordPress, SEO
   - Форумы: searchengines.guru, webmasters.ru
   - VK-группы по созданию сайтов
2. **Не спамьте ссылками!** Отвечайте на вопросы новичков:
   - «Какой хостинг выбрать?» → подробный честный ответ + ссылка
   - «Сайт тормозит» → совет по хостингу + ссылка
3. Используйте бота для генерации качественных ответов:
   `/content ответ на вопрос о выборе хостинга для форума`

**Ожидаемый результат:** 2–5 регистраций в первую неделю = **500–2000₽**

#### Стратегия «Telegram-канал» (быстрый старт)
1. Создайте узкотематический канал. Идеи:
   - «Сайты с нуля для новичков»
   - «WordPress без боли»
   - «Фрилансер о сайтах»
   - «Хостинги РФ: обзоры и промокоды»
2. Контент-план (через бота `/content`):
   - 3 поста в неделю: обзоры, инструкции, сравнения
   - 1 пост = 1 партнёрская рекомендация
3. Привлечение первых подписчиков (бесплатно):
   - **Взаимопиар** с каналами похожего размера
   - Кросс-постинг в свои личные соцсети
   - Ответы в комментариях крупных каналов со ссылкой на свой
   - Закладки в Pulse Mail.ru, VC.ru, Dzen со ссылкой на канал

**Ожидаемый результат:** 100–500 подписчиков за месяц, первые 3–10 регистраций

#### Стратегия «Фрилансер → клиенты» (самая быстрая конверсия)
Если вы делаете сайты на заказ:
1. Каждому клиенту **рекомендуйте хостинг** для размещения сайта
2. Используйте бота:
   `/content письмо клиенту с рекомендацией хостинга Beget`
3. Конверсия тут ВЫСОКАЯ (30–50%) — клиент доверяет вам как исполнителю

**Ожидаемый результат:** С 10 клиентов = 3–5 регистраций = **1500–5000₽/мес**
плюс **recurring** каждый следующий месяц

### ЭТАП 2. Масштабирование (1–3 месяца)

#### Добавляем YouTube (если готовы снимать)
- Видео-инструкции: «Как создать сайт на WordPress за 10 минут»
- В описании — партнёрская ссылка
- Бот помогает: `/content сценарий видео про установку WordPress на Beget`
- YouTube даёт **SEO-трафик на годы** — видео работают пассивно

#### Добавляем статьи на площадки (бесплатный трафик)
- **VC.ru, Dzen, Хабр, Pulse Mail.ru** — пишите статьи через бота
- Темы: «Топ-5 хостингов 2026», «Как я выбирал хостинг»
- В статье — ваша ссылка
- Эти статьи ранжируются в Яндексе/Google → пассивный трафик

### ЭТАП 3. Стабильный доход (3+ месяцев)

К этому моменту у вас:
- Несколько каналов трафика
- 20–50 привлечённых клиентов
- **Recurring доход** накапливается (эффект снежного кома)

**Реалистичные цифры к 6 месяцу:**
- 30 активных клиентов × средний чек 300₽/мес × 35% комиссии = **~3150₽/мес**
- И эта сумма РАСТЁТ каждый месяц

# ЧАСТЬ 4. Нужен ли сайт? Анализ

## Короткий ответ

**НЕТ, для старта сайт НЕ нужен.** Начинайте без него.
Сайт имеет смысл делать через 2–3 месяца, когда появится первый доход.

## Подробное сравнение

### Можно ли зарабатывать БЕЗ сайта? — ДА ✅

Рабочие каналы без сайта:
1. **Telegram-канал** — лучший вариант для РФ в 2026
2. **YouTube** — видео с ссылками в описании
3. **Статьи на VC.ru/Dzen/Хабр** — бесплатный трафик
4. **Форумы и чаты** — экспертные ответы
5. **Фриланс-клиенты** — прямые рекомендации
6. **Email-рассылка** — если есть база

### Когда сайт СТАНОВИТСЯ нужен?

Сайт окупается, когда:
- ✅ У вас уже есть трафик (хотя бы 500–1000 переходов в месяц)
- ✅ Вы заработали первые деньги и можете вложить ~3000₽/год
- ✅ Хотите пассивный SEO-трафик на годы вперёд

### Что за сайт делать? (когда придёт время)

НЕ корпоративный портал, а **простой одностраничник или блог**:
1. **Landing-обзор** — «Лучший хостинг 2026» с вашими ссылками
2. **Сравнительный сайт** — таблица хостингов с кнопками
3. **Блог** — статьи по SEO-запросам: «хостинг для wordpress», «дешёвый vps»

Технически:
- WordPress + тема (просто)
- Или Tilda (ещё проще, без кода)
- Или статический HTML (бесплатно, через GitHub Pages)

### Рекомендация по этапам

```
Этап 1 (месяц 1-2): БЕЗ сайта → Telegram + форумы + статьи на VC.ru
Этап 2 (месяц 3-4): Простой блог → SEO-статьи, ранжирование в Яндексе
Этап 3 (месяц 5+):   Полноценный сайт-агрегатор → максимальный охват
```

## 🔑 Главные принципы успеха

1. **Не спамьте** — давайте пользу, ссылка идёт естественно
2. **Будьте честны** — упоминайте минусы, это повышает доверие и конверсию
3. **Используйте бота** — он экономит часы на написании контента
4. **Анализируйте /stats** — какие посты/каналы приносят клики
5. **Фокус на recurring** — Timeweb, Beget, Sprinthost (повторные выплаты)
6. **Регулярность важнее объёма** — 3 поста в неделю > 30 за один день
7. **Один хостинг = одна ниша** — не мешайте все в один пост
